# Greenhouse RL Control — Setup & Usage

Reinforcement learning controller for a greenhouse HVAC system using [Sinergym](https://github.com/ugr-sail/sinergym) and EnergyPlus. The agent learns to operate heating and cooling systems to maintain thermal comfort while minimizing energy use.

---

## Installation

This project is built on top of the Sinergym framework. Follow the upstream setup first:

**1. Clone the base Sinergym repo and install dependencies:**

```bash
git clone https://github.com/ugr-sail/sinergym.git
cd sinergym
pip install poetry
poetry install
```

Or install via pip:

```bash
pip install sinergym[extras]
```

**2. Install EnergyPlus 23.2.0:**

Download the Linux installer from the [EnergyPlus releases page](https://github.com/NREL/EnergyPlus/releases/tag/v23.2.0) and run:

```bash
sudo ./EnergyPlus-23.2.0-*-Linux-Ubuntu*.sh
```

**3. Install additional dependencies used in this project:**

```bash
pip install stable-baselines3 wandb river
```

**4. Place the building and weather files:**

The required files are already in this repo:
- `sinergym/data/buildings/greenhouse_triangle_CoolingCoil_Heater.epJSON`
- `sinergym/data/weather/QAT_DA_Doha.404280_TMYx.2007-2021.epw` (and Khor, Al Kiranah)

## Running a Training Experiment

```bash
python scripts/train/local_confs/train_agent_local_conf.py \
    --config scripts/train/local_confs/ppo_greenhouse.yaml
```

---

## File Reference

### `scripts/train/local_confs/train_agent_local_conf.py`

The main training script. It reads the YAML config and orchestrates the full training loop:

- Builds the Sinergym/EnergyPlus environment with all wrappers applied
- Instantiates the PPO agent from Stable Baselines 3
- Applies a cosine learning rate schedule (3e-4 → 1e-5)
- Sets up a Weights & Biases logger if the `WandBLogger` wrapper is active
- Runs an evaluation callback every N episodes to track the best model
- Saves the best model at the end of training

### `scripts/train/local_confs/ppo_greenhouse.yaml`

The experiment configuration file. Everything about the run is defined here — no code changes needed to run a new experiment:

| Section | What it controls |
|---|---|
| `experiment_name` | Name used for W&B run and output folder |
| `environment` | Which registered Sinergym environment to use |
| `episodes` | Total number of training episodes |
| `algorithm` | SB3 algorithm class and all hyperparameters (learning rate, batch size, gamma, etc.) |
| `env_params` | Overrides for the environment: building file, weather files, reward function, observation variables, actuators, action space |
| `wrappers` | Ordered list of wrappers applied to the environment (discretization, observation building, normalization, logging) |
| `evaluation` | How often to run evaluation episodes and how many |

**Key env_params in this config:**
- `building_file`: `greenhouse_triangle_CoolingCoil_Heater.epJSON` — a vapor-compression cooling + electric heating greenhouse model
- `weather_files`: Three Qatar TMYx files (Doha, Khor, Al Kiranah) — rotated each episode for generalization
- `reward`: `ComfortGatedReward` — a comfort-gated reward that suppresses energy penalties when the zone is outside the comfort band
- `actuators`: four schedule actuators controlling heater fan availability, heater setpoint, cooler fan availability, and cooler setpoint

**Key wrappers in this config (applied in order):**
1. `HeatCoolModeDiscrete` — converts the 4D continuous actuator space into 5 discrete actions: OFF, HEAT-26°C, HEAT-28°C, COOL-18°C, COOL-20°C
2. `BuildStateWrapper` — constructs a structured observation vector from raw EnergyPlus outputs
3. `LaggedObservationWrapper` — appends the last 3 timesteps of key variables (temperature, electricity, outdoor temp) to give the agent short-term memory
4. `LoggerWrapper` / `CSVLogger` — logs episode data locally
5. `WandBLogger` — streams metrics to Weights & Biases for experiment tracking

## Notes

- The `.rdd` file (Report Data Dictionary) is generated by EnergyPlus on the first run. It lists all available variable names for the `variables:` section in the YAML. Find it at `<output_dir>/episode-0/output/eplusout.rdd`.
- Weather files must be `.epw` format. The three Qatar files used here are TMYx (Typical Meteorological Year extended) datasets.
- W&B logging is configured under `entity: sarazewial19-carnegie-mellon-university` and `project_name: PPPO-greenhouse-TimeConfig`. Update these in the YAML before running.
